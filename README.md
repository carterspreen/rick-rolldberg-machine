# ee241
EE241: Electric Circuit Analysis II Laboratory, Winter 2026, Cal Poly SLO

Arduino code that does simultaneous capacitive and inductive sensing, in order to play a classic music video :)
The setup we had to use in the class was super convoluted and noisy. 
I had to spend many hours tuning the capacitive sensing parameters in order to get this to work reliably. 
It is probably impossible to recreate, but the code is still here.
